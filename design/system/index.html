design/system

Durion Positivity Design System

Every component preview, rendered with src/styles.css and components.css. Rules and tokens are in README.md and tokens.json.

Navigation

AppShell

The authenticated frame: a 56px .shell-header on --navBackground above a 220px .shell-nav rail on --menuBackground, with the page on --themeBackground.

Layout

PageHeader

The top of every routed page: .page-header with an optional .overline, the h1, an optional .standfirst and the page's .header-actions.

Actions

Button

Triggers an action; one .btn base with a modifier for its weight.

Forms

Listbox

The dropdown panel for a combobox, typeahead or picker: .picker-wrap around the input, .picker-dropdown for the list, .picker-option per row.

Forms

TextField

A labelled input, select or textarea: a .field wrapper with a label, the control, and an optional hint or error.

Status

Badge

A square status tag on one of the six theme-aware status pairs: .badge plus .badge--<kind>.

Status

StatusChip

A small pill showing a record's state in a list or header: .dur-status plus a tone.

Feedback

Alert

An inline message banner tied to the page or form it sits in: .alert plus one tone.

Feedback

StatePanel

The empty, error or loading state that replaces a page's content: .state-panel, with skeleton rows while loading.

Surfaces

Card

A container on --cardBackground that groups one subject: .card, with --radius-md and --space-4 padding.

Surfaces

Dialog

A modal for a focused task or a confirmation: a native <dialog class="dialog" appModalDialog> with a .dialog-panel inside.

Data

DataTable

The list view for records: a .table-wrap (scrolls sideways on its own, --radius-lg, --border-color edge) around a table.data-table.

Iconography

Icon

Material Symbols Rounded, self-hosted, written as a ligature name inside <span class="material-symbols-rounded" aria-hidden="true">.
